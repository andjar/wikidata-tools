Reference fixer

Finds references whose reference URL (P854) starts with a given prefix, and adds properties to those references, e.g. stated in (P248) = NRK. It edits the existing reference (wbsetreference), so the statement, its qualifiers and its other references stay as they are.

Apply edits

Edits are made with your Wikidata account through an OAuth 2.0 access token. To get one, register an owner-only OAuth 2.0 consumer: tick “This consumer is for use only by …”, and choose the grants Basic rights and Edit existing pages. Owner-only consumers are approved automatically. Copy the access token you are shown. The token goes only to wikidata.org.
