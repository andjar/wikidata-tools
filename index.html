Wikidata tools

Small tools for the repetitive parts of Wikidata editing. Each one is a single page that runs in your browser. Most of them produce QuickStatements for you to check before anything is edited.

📚

Reference URL → QuickStatements

Finds every item that cites a URL, or any page under it, and adds the same statements to all of them.

Reference fixer

Adds properties to existing references whose reference URL matches a prefix. The statement, its qualifiers and its other references are left untouched. You check every change in a preview first.

Chain builder

Loads items with SPARQL, lets you drag them into order, and writes the follows / followed by links. Links that already exist are locked, and breaks mark gaps or unknown items.

Runs in your browser

No server, no account and no tracking. The pages talk directly to the Wikidata API and the query service.

You review before anything changes

The QuickStatements tools only produce commands. You run them yourself in QuickStatements. The reference fixer shows every change and edits only the rows you select.

Shareable setups

Every tool reads its settings from the page link, so you can bookmark one setup per source, series or office.
